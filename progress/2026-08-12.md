### Texture language: line art out, material grain in

Darius rejected both wave-line attempts ("messy and inorganic"). Competitor
survey settled it — OARS runs plain white, Western River parchment grain,
AzRA canvas grain; **nobody uses vector strokes**, which at whisper opacity
only ever read as ruled lines or debris.

- New `.bg-canvas`: static `feTurbulence` grain (animated grain reads as TV
  static). Applied to the itinerary band, the contact evergreen panel,
  PageBuilder dark blocks, and every sand `Section` (review band, blog band).
- `.bg-topo` + drift animation deleted. Zero topo references left in src/.
- `TopoDivider` removed entirely (footer was the only consumer) after Darius
  cut it on sight — see bug below.

### Bugs found

1. **Footer TopoDivider was invisible to motion-enabled visitors since the
   reveal system landed.** It hardcoded `data-reveal`, but `RevealObserver`
   only observes `main [data-reveal]` and the footer renders outside
   `<main>` — so reveal CSS hid it at opacity 0 and nothing ever revealed
   it. Reduced-motion users (and every axe run, which emulates reduced
   motion) saw it fine, which masked the bug in all screenshots. Fixed by
   making reveal opt-in on the component, then mooted by deleting it.
   **Lesson for the reveal system: any `data-reveal` outside `<main>` is a
   permanent-invisibility bug the a11y suite structurally cannot catch.**
2. `AmbientVideo` src-detach reload bug, above.

## Decisions

- Full-bleed video with scrim, not a side panel (Darius call).
- Material grain, not line art, as the site texture (research-driven).
- Grain is never animated; sand cards (TripCard) stay grain-free.
- Topo motif retired site-wide, including the footer divider.

- **Hero aspect**: desktop height was a fixed 523px at every width, so wide
  screens degraded into a thinner letterbox crop. Now `md:aspect-[1440/523]`
  (the mock's proportion) with a 75vh cap; Sanity crop request aligned to the
  same box at 2x (2880×1046). Mobile unchanged. Also migrated `priority` →
  `preload` on Hero images (Next 16 deprecation).
- **Rafting Since 1966 collage enlarged to mock geometry**: collage column
  now `3.2fr` vs `1fr` copy rail (was 1.3fr/1fr); near-square (8:9) action
  shot, 2:3 Dee portrait, and copy all hang top-aligned from the same line,
  with Dee running past both (was two equal small 3:4s, centered). Took a
  second pass — the tiny mockup read as a landscape-centered layout; Darius's
  zoomed crop showed square/top-aligned.
- **Story photo replaced**: uploaded Darius's color rapids action scan
  (`Folder005_00001A.jpg`, downscaled to 3000px) to Sanity as
  `homepage.storyImageLeft`, replacing the B&W vintage shot. Previous asset
  ref (recoverable in Studio):
  `image-d004cb2849ad0596c5459005ccae0366415e4665-4086x5374-jpg`.
- **Dee portrait cropped to full bleed**: the scan has baked-in white
  polaroid borders (top 4%, bottom 4.5%, left 8%, right 6.5%, measured by
  pixel-scanning the asset). Set a Sanity-level `crop` on
  `homepage.storyImagePortrait` (no code change; adjustable in Studio) so the

- **RiverSelector images**: switched from raw CSS `background-image` (one

- **River selector links retargeted** (Darius call: river pages are too thin

  the river has exactly one trip (six of nine do), else falls back to
  `/trips`. Implemented via `tripCount`/`tripSlug` in the homepage query;
  typegen regenerated. `/rivers/[slug]` pages still exist but nothing on the
  homepage links to them.
