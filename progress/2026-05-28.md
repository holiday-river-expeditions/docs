Holiday set up an Adobe Fonts (Typekit) web project for the brand display typeface, ATF Alternate Gothic, on their Creative Cloud account. Wired the kit into the site, resolving the long-standing pending item from the brand refresh.

- Kit ID is a public, non-secret value, so it's inlined rather than moved to an env var.

### Dependency major-version upgrades (PR #43)

Follow-up pass to bring dev dependencies to their latest majors, done on `feature/dep-upgrades`, one bump at a time with full verification (typecheck/lint/test/build) after each so any breakage stayed isolated.

- **Landed:**
  - `@types/node` 20 → 25 (types-only)
  - `jsdom` 28 → 29 (test environment only)
- **Deferred — ecosystem-blocked, reverted:**
  - `@vitejs/plugin-react` 5 → 6 requires `vite ^8.0.0`, but vitest 4.1.7 pins vite 7.x. Needs a coordinated vite 8 + vitest-major migration. Revisit when vitest ships on vite 8.
  - `eslint` 9 → 10 — `eslint-config-next`'s bundled plugins (react / import / jsx-a11y) don't support eslint 10 yet (unmet peers + runtime crash from the changed rule-context API). Revisit when Next's lint config supports eslint 10.

**Decision:** upgrade only what the ecosystem currently supports; hold the two blocked majors rather than force them. No application code changes.
